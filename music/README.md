# Music library

Add MP3 tracks here that you are licensed/allowed to use.

Recommended setup:
- Download tracks manually from YouTube Studio > Audio Library.
- Prefer tracks marked **Attribution not required** for simpler automation.
- Put the MP3 files in this folder.
- Name files with a category keyword, for example:
  - `krishna_devotional.mp3`
  - `shiv_devotional.mp3`
  - `hanuman_devotional.mp3`
  - `ram_devotional.mp3`
  - `mata_devotional.mp3`
  - `general_bhakti.mp3`

The automation selects a track by topic/category and mixes it into the final 9:16 video with FFmpeg.

Do not upload copyrighted commercial songs unless you have the necessary rights. YouTube states that Audio Library music can be downloaded and used in videos; Creative Commons tracks require attribution, while tracks marked as attribution-not-required do not. See: https://support.google.com/youtube/answer/3376882
